# pneutype

Low-boilerplate creation of newtypes defined by validation constraints.

## Synopsis

Easily create newtypes analogous to `String` and `str` that obey a particular validation constraint.  See `pneutype` crate docs.

## Notes

In order to debug errors in the derived code, which often give completely opaque error messages, add `write_generated_code` attribute to the `pneu_string` or `pneu_str` attribute.  This will cause the generated code to be written to a file named `derive_pneu_string.{TypeName}.rs` or `derive_pneu_str.{TypeName}.rs`.  Run the tests for the `pneutype-derive-tests` crate to see an example of this with the `SuperSecret` and `SuperSecretStr` types.

    cargo test -p pneutype-derive-tests

Another useful method for debugging is use of the [cargo-expand](https://crates.io/crates/cargo-expand) crate:

    cargo expand -p <item-name>

This will show the code generated by the proc macro.  For example,

    cargo expand -p pneutype-derive-tests

See [cargo-expand](https://crates.io/crates/cargo-expand) for usage details.
